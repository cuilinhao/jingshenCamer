# TestCamer 拍后景深 v2 真机验收

状态：待用户或具备设备的开发者执行。未预填“通过”。参考人物照片／杯子照片是目标，不是本工程已经生成的效果。

## 首轮四步

1. 打开新工程运行到 iPhone，确认桌面名称“TestCamer 景深v2”和顶部“拍后景深 · v2”。保持后置镜头，允许相机权限。
2. 光圈选 f/1.4，拍摄有前后距离的场景。点选人物衣服内部或杯盖内侧，等普通预览中物理对焦稳定后按快门。不要仅拍一面无纹理的白墙。
3. 成片出来按住“看原图”比较同一次照片。预期所选深度附近更清晰、较远背景有虚化；有明显更近物体时也应有近景虚化。
4. 点“景深诊断”：记录完整状态和分布图。保存后在系统相册打开成片，再核对不是原图或结果页缩略图。

## 看诊断，而不是只看 f 值

`requestedDepth=false`：当前请求未启用原生深度，检查开关和能力提示。

`deliveredDepth=false`：本次照片回调没有交付深度，不能用模糊图片冒充成功。

`directDepthCopy=false`：深度复制失败，查看 depthCopyIssue。

`insufficientSeparation`：剔除异常值后层次不够，或者没有足够的近／远景虚化区域；改变物体前后距离再测。

`focusUnavailable`：选区没有足够有效样本，点选主体内部而非细小边缘后重拍。

`alignmentMismatch`：照片／深度比例不同，已停止错误配准。

`weakEffect`：完成处理但目标区域像素变化不足；可能是纯色场景、f/16、小深度差或渲染问题，不能只凭这个状态判定是哪一种。

`applied`：最终像素检测到变化，**仍需肉眼验收主体、边缘和背景虚化**。这不是算法效果已经等同参考 App 的证明。

诊断图的亮灰／白色表示虚化半径较大，黑色可能是清晰带，也可能是无效深度；两者未分别染色。近景轮廓扩散范围未单独画出，诊断图不是完整合成边界的精确截图。
