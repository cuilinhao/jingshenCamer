# 景深开启但无效果：修复与验证

日期：2026-09-21。环境：macOS、Xcode 27.0（27A266a）、Swift 6.4。

## 已复现的原因

非人脸近景主体偏离画面中心时，Core Image 的默认自动焦点可能选中背景。滤镜仍能输出图片，但像素与原图完全相同。旧处理器仅凭 `createCGImage` 非 nil 就返回 `applied`，因此界面显示“景深成片”却没有虚化。

使用生成的带真实辅助视差数据的 HEIC，直接调用旧生产处理器，复现了 `outcome=applied` 且背景像素平均差为 0 的红灯。该测试不依赖相机、不使用模拟滤镜。

## 修复

- 点按对焦位置仅在内存中传给下一次快门，按传感器坐标、EXIF 方向及镜像转换为景深滤镜的清晰区域；快门、重拍/停止或切摄像头后清空。
- 未点按时保留系统自动选择；若输出无明显变化，再从同张照片的真实视差中选择连续近景小区域重试，不更改视差数值、不增加全图模糊。
- 比较相同色彩空间下的实际渲染像素；无明显变化时返回 `noVisibleEffect` 并保存普通照片，不再显示“景深成片”。
- 提取 `CaptureTypes.swift` 使原生渲染回归可以直接编译生产类型；保存的 JPEG 不带焦点或辅助深度。

## 验证边界

这些检查证明修复了可复现的原生自动焦点无效果路径，不代表已经完成用户 iPhone 17 后置相机的现场成片验收。设备在调试时锁屏，无法启动拍摄来核对真实场景。

自动近景选择依据连续深度区域，不是语义识别；复杂遮挡、细小主体、弱纹理或很轻微的虚化仍需按《真机验收.md》检查。像素判定先在原分辨率上计算差异，再以 CIAreaAverage 规约，以 0.5/255 的平均线性 RGB 差作为“变化不明显”阈值，避免缩小图片抹掉细密纹理上的真实虚化。
