# 拍后换焦与本机编辑验收

## 已实现的交互和数据流

拍摄成功且深度有效后自动进入景深编辑：点击切换焦点、f/1.4～f/16、按住原图、恢复初始、本机自动保存、图库重开/删除、完整分辨率 JPEG 相册导出。连续操作合并，过期结果不显示不保存；每次从原始容器生成。导出期间锁定参数。本机保存失败可重试，退出前明确告知未保存。

## 自动验证

执行 `bash Scripts/verify_on_mac.sh`，包含原有规则/数学/日志/渲染测试、iOS SDK 不签名构建、新存储/会话/编辑渲染测试。独立 iOS 27 模拟器还执行了同一合成 HEIC 的原生 factory / 兼容 factory / 手动 RGB+disparity 探针。

本轮执行结果：iOS SDK 不签名构建成功；存储 54 项、会话/坐标 30 项、编辑渲染 145 项通过；原有规则 25 项、深度数学 88 项、日志 22 项、原生渲染 94 项、苹果适配器 58 项及 14 项 Python 检查通过。仅存在无 AppIntents 依赖的元数据提取提示。日志 `/tmp/testcamer-refocus-final-verification.log`。

iOS 27 独立 QA host 复用了实际编辑器和图库 UIKit 源码，已运行并检查初始布局，无文字遮挡或控件溢出。截图：`/tmp/testcamer-layout-qa/editor-layout.png`、`/tmp/testcamer-layout-qa/library-layout.png`。通过 App 窗口绘制获取，未执行点击/手势或真实相册保存验收。

## 未达成的视觉验收

原生录屏里“选后方抽屉时前方鼠标盒明显虚化”仍未验收通过。

macOS 与 iOS 27 模拟器探针测得（合成照片纹理强度，越大越清晰）：

| 输入/兼容苹果处理 | 近处 | 远处 |
| --- | ---: | ---: |
| 原图 | 30.638 | 34.043 |
| 选择近处 | 30.638 | 约 0.39 |
| 选择远处 | 30.638 | 34.043 |

保留完整辅助 metadata 的 factory 在这一合成输入上输出原图。兼容 factory 和直接 RGB+disparity 接口均能改变远景，却没有产生所需的近景虚化。未将此差异改写为通过。

严格探针：`bash Scripts/verify_photo_editing_render.sh --require-foreground-blur`。普通回归会单列 8 个 EXIF 情况的 `NOT VERIFIED / KNOWN DIFFERENCE`，严格模式将其计为失败。合成输入结果不等同于真实相机深度/遮罩结果，必须继续真机对照。

## 真机步骤

1. 相同办公桌摆放近处盒子、较远小盒、远处抽屉；拍摄 f/1.4 景深照片。
2. 点击近处和远处，检查焦点框对应点位、边缘过渡和前后虚化。明确记录远焦时近景是否仍清晰。
3. f/1.4 与 f/16 来回调整；连续快速点选后检查最终画面和参数属于最后一次操作。
4. 按住原图、恢复初始；初始同帧对照的显示不能改变当前编辑或保存内容。
5. 完成后重启 App，从可编辑照片重开；确认效果与焦点/光圈保留，恢复初始仍有效。
6. 保存到相册；检查完整分辨率、方向、色彩及最终焦点。拒绝相册权限后本机编辑仍保留。
7. 从列表删除一份测试照片，确认本机列表移除且已经导出的相册 JPEG 仍在。
8. 前摄/横竖方向/镜像均检查点位；点击照片留白不得移动焦点。
9. 普通照片或无效深度不应提供误导性的可编辑记录；渲染或保存失败要显示错误并保留已成功版本。

本轮没有安装到真实手机或验证真实镜头拍摄画质。
