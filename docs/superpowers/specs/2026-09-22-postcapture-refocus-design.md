# 拍后换焦与本机可编辑照片

用户已确认并要求开始实现：拍后点击不同物体换焦、f/1.4–f/16 调整、按住原图、恢复初始效果、关闭 App 后重新编辑、系统相册导出最后效果。实现使用公开苹果景深 API，画质由真实原图和深度决定，系统相册原生换焦控件不在本次保证范围。

## 设计

- 独立成片编辑页持有完整未虚化相机容器及初始/当前编辑参数。屏幕点位先排除 aspect-fit 留白，再转换到原始传感器归一化坐标（含 EXIF 镜像）。
- PhotoEditingRenderer 在串行后台队列从同一原图产生预览与全分辨率导出。焦点和虚拟光圈使用现有 AppleDepthRenderer，禁止从前一张已虚化成片递归渲染。
- 编辑协调器合并连续请求：当前渲染结束后只取最新参数，过期结果不显示/不保存。导出锁定当前参数，失败时不导出旧画面冒充成功。
- EditablePhotoStore 在 Application Support 保存原始容器、版本化参数及预览。提交以原子更新保证数据一致性；列表可打开和删除，删除包含整份本机源数据。照片生成后先存初始版本；成功编辑再自动保存，失败明确提示。
- 主拍摄页保留既有普通成片与诊断。支持景深的成片自动进入编辑页；主页的“可编辑照片”打开本机列表。相册只收到最后参数渲染的完整尺寸 JPEG。
- 深度缺失/无效时沿用普通成片流程；不产生可换焦的误导入口。存储失败不隐瞒、不覆盖之前有效版本。

## 验证

文件往返/覆盖/删除/损坏隔离；连续请求仅最新生效；EXIF 1–8 和留白坐标；真实 Core Image 前后焦点和光圈图像差异；预览/导出尺寸与无深度失败；iOS SDK 编译与已有完整测试。真机画质、交互耗时和相册权限需要实机验收。
